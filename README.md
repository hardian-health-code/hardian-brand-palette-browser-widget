# hardian-brand-palette-browser-widget
Simple Chrome-based widget for storing brand hex codes

![Brand widget screenshot](https://github.com/hardian-health-code/hardian-brand-palette-browser-widget/blob/main/Brand%20widget.png?raw=true)

## Installation

 - Download all files - click the <>Code drop-down (top right) in Github --> Download Zip
 - Unzip the folder and rename EXACTLY to '**Hardian Brand Palette**' on your machine into a folder where it wont be moved/deleted.
 - Open Chrome / Brave and navigate to chrome://extensions/
 - Toggle Developer mode ON (top right corner).
 - Click Load unpacked (top left).
 - Select the "Hardian Brand Palette" folder.
 - Click the "puzzle piece" icon in the top right of Chrome to pin the Hardian widget to the toolbar for permanent access.

## Usage

- Left click the widget in your browser toolbar.
- Left click a colour hex code from the list to automatically copy it to your clipboard.
- Paste the hex code into any application or document as required.

- You can also add additional hex codes to the widget using the Add function.
